# Reproduced Run

`stps_v2_hard_reproduction.json` is an independently generated fixed-input
STPS v2 run performed on July 29, 2026 with the archived runtime, checkpoints,
and `neupan` environment snapshot.

It is not the canonical poster evidence. The canonical reported results remain
under `src/results/final/`. The rerun exactly matches three scenarios and
differs by one of twelve starts in the U-trap seed-123 group. The details and
the reason for retaining both files are documented in `REPRODUCIBILITY.md`.

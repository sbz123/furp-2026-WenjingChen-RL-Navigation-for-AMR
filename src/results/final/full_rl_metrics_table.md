# Full RL Metrics

These metrics are for the standard 100-episode evaluation and can be used as supplementary RL-navigation metrics in the report or appendix.

| Metric | CNNTD3 baseline | STPS v2 |
|---|---:|---:|
| Success Rate | 80% | 81% |
| Collision Rate | 19% | 19% |
| Average Reward | 63.5 | 65.6 |
| Average Path Length | 4.13 m | 5.59 m |
| Path Efficiency | 0.93 | 0.81 |
| Average Steps | 32 | 41 |

Note:

- Success Rate is the primary metric in the poster.
- Collision rate, reward, path length, path efficiency, and steps are supplementary diagnostics.
- The hard-scenario result table remains the main evidence for STPS because STPS is designed for trap recovery.
